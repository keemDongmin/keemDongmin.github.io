01Project Intro

젠레스 존 제로의 프로미아 캐릭터 플레이 영상을 기반으로 제작한 사운드 리디자인 프로젝트입니다.


단순한 사운드 재현이 아닌, 영상의 내러티브를 음향으로 설계하는 것에 초점을 맞췄습니다. 인간 경매라는 긴장된 상황에서 프로미아의 등장과 복수로 이어지는 극적 흐름을 오케스트라 구조 안에서 표현했습니다.


BGM 기획부터 보이스, 왈라, SFX, 최종 믹싱까지 전 과정을 단독으로 설계하고 제작했습니다.

02Concept
기획 의도
영상 속 인간 경매 → 프로미아 등장 → 복수라는 내러티브를 음향 구조로 번역했습니다.
오케스트라의 긴장감이 침묵을 거쳐 폭발하고, 다시 여운으로 닫히는 흐름 — 복수의 쾌감을 사운드로 설계하는 것이 이 프로젝트의 핵심이었습니다.
Phase 01 — Intro
긴장 — 경매장의 위압감
서스테인 바이올린과 낮은 피아노 노트로 불안한 분위기를 조성. 스타카토 첼로가 긴장감을 서서히 끌어올린다.
Phase 02 — Section A
고조 — 에너지 상승
스피카토 현악 오스티나토와 팀파니 리듬이 맞물리며 브라스 스웰이 더해진다. 무언가 터지기 직전의 압박감.
Phase 03 — Trigger
반전 — 프로미아 타이틀 등장
소리가 점점 줄어들다 완전한 침묵. 현악기 어택과 SFX 레이어가 결합된 임팩트 히트가 터지며 음악이 전환된다.
Phase 04 — Section B
폭발 — 오케스트라 하이브리드
풀 오케스트라 크레셴도 위에 하이퍼 에너지가 얹힌다. 단절이 아닌 융합 — Zap 베이스 사운드로 통일된 캐릭터 아이덴티티.
Phase 05 — Outro
여운 — 복수 이후의 침묵
볼륨이 급락하고 피아노 잔향과 페이딩 스트링 패드만 남는다. 쾌감 이후의 감정적 여운을 음향으로 닫는다.
BGM 프롬프트 설계
[Intro]
sustained high-register violin pad
low piano note
staccato cello and bass motif enters
→ 경매장의 억압적인 분위기와 불안감을 조성하기 위해 고음역 바이올린 서스테인과 낮은 피아노를 선택.
[Section A]
spiccato string ostinato
rhythmic timpani hits
brass swells, rising intensity
→ 아직 터지지 않은 긴장 상태를 유지하면서 에너지를 서서히 끌어올림. 브라스 스웰로 압박감 가중.
[Section B]
full orchestral crescendo
heavy percussion hits
staccato brass stabs, rapid violin runs
→ 프로미아 등장 이후 복수의 폭발. 오케스트라 위에 하이퍼 에너지를 얹어 단절 없는 융합감 표현.
[Outro]
sudden drop in volume
lingering piano resonance
fading string pad
→ 복수 이후의 감정적 여운. 쾌감이 지나간 자리의 침묵을 표현.

05Summary

이 프로젝트는 "사운드로 내러티브를 설계한다"는 관점에서 출발했습니다.


영상의 극적 흐름을 분석하고, 각 국면에 맞는 음향 언어를 선택하고, AI 툴과 직접 제작한 SFX를 하나의 파이프라인으로 통합하는 — 기획자이자 사운드 디자이너로서의 작업 방식을 보여주고자 했습니다.


사운드는 플레이 경험을 완성합니다.
